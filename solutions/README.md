# Solutions

Reference solutions for the exercises in this repository. Open a solution alongside its exercise notebook to check your work.

| File | Description |
|---|---|
| [**02 - Exercise: Feature Engineering Basics**](02_exercise_feature_engineering_basics.ipynb) | Worked solution: median and most-frequent imputation, one-hot encoding and min-max scaling, applied step by step to the training and the test data. |
| [**04 - Exercise: Column Transformers and Pipelines**](04_exercise_pipelines.ipynb) | Worked solution: the same preprocessing as a `ColumnTransformer` with pipelines, plus the bonus model pipeline. |
| [**05 - Exercise: Feature Engineering on a Real Dataset**](05_exercise_diamond_prices.ipynb) | Worked solution: four model versions compared on the validation set (numeric features, ordinal grades, one-hot grades, log transform), the test score of the chosen version, and two bonuses: polynomial terms, feature selection with correlations, group-wise removal and RFE, and a volume feature created by hand. |
